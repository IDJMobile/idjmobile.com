Creating Archives¶

libNeoAppleArchive provides functionality for creating Apple Archives from files and directories.

The library uses NeoAAArchivePlain to represent an uncompressed Apple Archive. You can create an archive from a directory, optionally compress it, and write the resulting archive to disk.

Creating an Archive from a Directory¶

The first step is to create a NeoAAArchivePlain from an existing directory.

The function used for this is:

NeoArchivePlain neo_aa_archive_plain_from_directory(const char *path);

The function takes a directory path and creates an archive containing its contents.

If archive creation fails, the function returns NULL.

For example:

NeoArchivePlain archive = neo_aa_archive_plain_from_directory("my_directory");

if (!archive) {
    fprintf(stderr, "Failed to create archive from directory\n");
    return 1;
}

At this point, you have an uncompressed Apple Archive represented by NeoArchivePlain.

Compressing and Writing an Archive¶

Once you have created a NeoArchivePlain, you can compress it and write it to a file using:

neo_aa_archive_plain_compress_write_path(archive, compress, outputPath);
  • archive: The NeoArchivePlain you want to compress and write.
  • compress: The compression selection used when writing the archive.
  • outputPath: The destination filepath for the resulting Apple Archive.

The compression selection should use one of the values supported by the library's API.

This function provides a convenient way to create compressed Apple Archives without manually handling the individual archive entries.

Code Example¶

The following example is based on the archiving implementation in the official neoaa command-line tool.

#include <stdio.h>
#include "libNeoAppleArchive.h"

int main(void) {
    NeoArchivePlain archive = neo_aa_archive_plain_from_directory("my_directory");

    if (!archive) {
        fprintf(stderr, "Failed to create archive from directory\n");
        return 1;
    }

    /* Compress and write the archive */
    neo_aa_archive_plain_compress_write_path(archive, NEOAA_COMPRESS_LZFSE, "output.aar");

    /* Destroy the archive when finished */
    neo_aa_archive_plain_destroy_nozero(archive);

    printf("Archive created successfully!\n");
    return 0;
}

The header name and include path should also be adjusted to match your project setup.

Releasing Resources¶

After you have finished using a NeoAAArchivePlain, you should destroy it to release its allocated resources.

For the example above, this is done using:

neo_aa_archive_plain_destroy_nozero(archive);

Make sure you destroy the archive when you no longer need it.

Additional Information¶

NeoAAArchivePlain is useful when you want to work directly with the contents of an Apple Archive.

If you are instead working with an existing compressed archive, you may want to use NeoAAArchiveGeneric to decompress it.

See the NeoAAArchiveGeneric documentation and the API Reference for additional information about working with archive types and their associated functions.
