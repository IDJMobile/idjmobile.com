Installation¶

Current Availability¶

Currently, libNeoAppleArchive does not provide prebuilt dynamic libraries. To use the library, you must build it from source.

Prebuilt dynamic library distribution is something that may be introduced in the future.

Obtaining the Source Code¶

The source code is hosted on GitHub:

https://github.com/0xilis/libNeoAppleArchive

Important: libNeoAppleArchive uses Git submodules for some of its dependencies. You must fetch these submodules when obtaining the repository. A regular git clone without initializing the submodules is not sufficient.

The recommended way to obtain the repository is:

git clone --recurse-submodules https://github.com/0xilis/libNeoAppleArchive.git
cd libNeoAppleArchive

If you have already cloned the repository without fetching its submodules, you can initialize and update them with:

git submodule update --init --recursive

Building from Source¶

From the repository's root directory, run:

make

The Makefile builds the required compression dependencies and produces a static library.

The resulting library is located at:

build/usr/lib/libNeoAppleArchive.a

The build also creates supporting files and directories under build/.

Build Dependencies¶

The build requires a working C compiler and Make. The current Makefile uses Clang by default.

Depending on your operating system, you may also need to install development packages for dependencies such as OpenSSL and zlib.

The repository includes some compression dependencies as Git submodules, so make sure these have been initialized before building.

Using the Library¶

After building, you can use the resulting static library in your own C projects.

The library's headers are located in the source repository under libNeoAppleArchive/. The build output currently places the static library in build/usr/lib/.

When compiling your own application, you will need to provide the appropriate include paths and link the static library along with its required dependencies.

For examples of using the library, continue to:

  • Extracting Archives
  • Creating Archives

For additional information about individual functions and types, see the API Reference.
