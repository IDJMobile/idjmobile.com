Extracting Archives¶

libNeoAppleArchive provides a convenience function for extracting an Apple Archive directly to a destination directory.

You do not need to manually decompress the archive or iterate through its entries when using this function.

Extracting an Archive to a Directory¶

The function used for this is:

int neo_aa_extract_aar_to_path_err(const char *archivePath, const char *outputPath);
  • archivePath: Path to the Apple Archive you want to extract.
  • outputPath: Destination path where the extracted archive contents should be placed.

Return Values¶

The function returns an integer indicating whether extraction succeeded.

Return value Meaning
0 Extraction succeeded.
Negative value Extraction failed. The value represents an error code.

Always check the return value so that your application can handle extraction failures appropriately.

Supported Archive Formats¶

The extraction function supports the following archive formats:

Format Compression Magic
RAW None AA01 / YAA1
PBZZ ZLIB PBZZ
PBZE LZFSE PBZE
PBZB LZBITMAP PBZB
PBZM LZRAVEN PBZM

This allows the function to extract both uncompressed Apple Archives and archives using several supported compression formats.

Memory Usage¶

The extraction function uses different approaches depending on the compression format.

Streaming extraction:

  • RAW
  • PBZZ (ZLIB)

These formats are extracted using streaming operations to minimize memory usage.

In-memory decompression:

  • PBZE (LZFSE)
  • PBZB (LZBITMAP)
  • PBZM (LZRAVEN)

These formats are currently decompressed in memory because streaming decompression implementations are not available for them.

This means that extracting archives using these compression formats may require additional memory, particularly when working with large archives.

Code Example¶

The following example demonstrates extracting an Apple Archive and checking whether the operation succeeded.

#include <stdio.h>
#include "libNeoAppleArchive.h"

int main(void) {

    int result = neo_aa_extract_aar_to_path_err("example.aar", "extracted");

    if (result) {
        fprintf(stderr, "Failed to extract archive. Error code: %d\n", result);
        return 1;
    }

    printf("Archive extracted into extracted/ successfully!\n");
    return 0;
}

The header name and include path in this example should be adjusted to match how you have integrated the library into your project.

Additional Information¶

If you need more control over the extraction process, libNeoAppleArchive also provides lower-level APIs for working with archive contents directly.

For example, you can use NeoAAArchiveGeneric to represent a potentially compressed archive and access its uncompressed NeoAAArchivePlain through the raw field.

See the NeoAAArchiveGeneric documentation and the API Reference for more information.
